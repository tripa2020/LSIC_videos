# plans/ — the living board

**Read this first, every session.** This file is the answer to "what is going on right now."
Whoever changes an effort's state updates its one line here, in the same commit.

**Folder = status.** Nothing here carries a prose Status header that can rot:

- `plans/*.md` — **ACTIVE** (open work)
- `plans/archived/*.md` — **DONE or SUPERSEDED** — history only, never drive work from there

An effort moves to `archived/` when its milestones are **green + verified** (the CLAUDE.md §3
discipline), or when a newer doc supersedes it (the mover names the successor in the old plan's
header and below). A pair moves **together** — the frozen `_DESIGN_RATIONALE.md` follows its
`_PLAN.md`.

Each major effort is a pair generated by `/deep-plan` (Phase 4, from
`.claude/skills/deep-plan/reference/plan-template.md` — see CLAUDE.md §1):

- `<NAME>_PLAN.md` — **durable**, the living source of truth, kept synced to the code.
- `<NAME>_DESIGN_RATIONALE.md` — **frozen** provenance, written once, never updated.

Anything smaller than a major effort just updates the master [PLAN.md](PLAN.md) here.
